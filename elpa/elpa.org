* Loading helper

See the Loading helper section of emacs-config.org.  Required here as
well so this file does not depend on elisp.org having run first.

#+BEGIN_SRC emacs-lisp
  ;;; elpa.el --- tangled by org-babel-load-file  -*- lexical-binding: t; -*-
  (add-to-list 'load-path "~/.emacs.d/emacs-config/elisp/")
  (require 'my-require)
#+END_SRC


* Color theme

Activate the "Yantosca" custom color-theme, which has been added to the
elpa/color-theme-6.6.1 folder.

NOTE: We will not activate this color-theme if we have started emacs
with the -nw (no-windowing-system) option.

#+BEGIN_SRC emacs-lisp
  (add-to-list
   'load-path
   "~/.emacs.d/emacs-config/elpa/color-theme-6.6.1")
  ;; color-theme is only required on a graphical frame, so the byte
  ;; compiler never sees its definitions and warns about all three of
  ;; them plus color-theme-is-global.  The require above this guard is
  ;; what supplies them at runtime.
  (with-no-warnings
    (when (and (display-graphic-p) (my-require 'color-theme))
      (setq color-theme-is-global t)
      (color-theme-initialize)
      (color-theme-yantosca)))
#+END_SRC


* YASnippets

Activate the YASnippets package.

#+BEGIN_SRC emacs-lisp
  (add-to-list 'load-path
   "~/.emacs.d/emacs-config/elpa/yasnippet-0.14.0")
  (when (my-require 'yasnippet)
    (yas-global-mode 1))
#+END_SRC

Load some classic snippets for various major modes.

#+BEGIN_SRC emacs-lisp
  (add-to-list 'load-path
   "~/.emacs.d/emacs-config/elpa/yasnippet-classic-snippets-1.0.2")
  (my-require 'yasnippet-classic-snippets)
#+END_SRC
